# Как привязать Discord-аккаунт на SunShine

**1.** Зайди на сервер и напиши в чат команду:
```
/sunshine link
```

**2.** В чат придёт твой код — 4 цифры, например `0252`.

**3.** Открой Discord, найди бота **SunShine** в списке участников сервера и напиши ему **в личные сообщения** (ЛС) только этот код, ничего больше:
```
0252
```

**4.** Бот ответит "✅ Аккаунт успешно привязан" — всё готово.

---

Если код не сработал (написал "неверный или устарел") — зайди на сервер и напиши `/sunshine link` заново, чтобы получить новый код.

Отвязать аккаунт: `/sunshine unlink`
