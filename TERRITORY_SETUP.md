# Установка: общины/территории

## 1. Какие файлы куда класть

| Файл | Куда | Обязателен? |
|---|---|---|
| `SunShine-1.0.0.jar` | `plugins/` | да, это основной плагин |
| `TerritoryTitles.jar` | `plugins/` | да — без него тайтлы/защита территорий не заработают |
| `config-deployed.yml` → переименовать/слить в `plugins/SunShine/config.yml` | — | см. шаг 3 |
| BlueMap | `plugins/` | нет, опционально (карта территорий) |
| PlaceholderAPI | `plugins/` | нет, опционально (тег общины в игровом чате) |

**Порядок установки:**
1. Останови сервер.
2. Замени `SunShine-1.0.0.jar` в `plugins/`.
3. Положи `TerritoryTitles.jar` в `plugins/` (если ещё не стоит).
4. Обнови `config.yml` SunShine — добавь блок `territory:` (см. ниже), если его там ещё нет.
5. Запусти сервер.

TerritoryTitles ничего не нужно настраивать отдельно — SunShine управляет им сам через встроенный код.

---

## 2. Права доступа перед запуском

`TerritoryTitles.jar` даёт две permission-ноды (по умолчанию — только у оператора/`op`):
* `territorytitles.admin` — команда `/zone` (ручная разметка зон, не связана с общинами).
* `territorytitles.bypass` — игнорирует защиту/закрытие ЛЮБОЙ зоны, включая территории общин. Выдавай
  только реально доверенным людям (модераторам, себе) — обычным игрокам не давать.

---

## 3. Конфиг SunShine — блок `territory:`

В `config.yml` SunShine (или `config-deployed.yml`, если правишь именно его) должен быть такой блок:

```yaml
territory:
  enabled: false          # включи true, когда заполнишь всё ниже
  world: "world"           # мир, где разрешено создавать территории
  admin-role-ids: []       # ID Discord-ролей с доступом к "Админ-панели" и логам
  channels:
    review: ""             # заявки на создание/расширение (кнопки Одобрить/Отклонить)
    list: ""                # автообновляемый список общин
    log: ""                 # лог админ-действий (кик/передача/ограничения/удаление)
    panel: ""               # канал с единой панелью управления (кнопки для игроков)
  list-banner-url: ""      # картинка-шапка для списка общин, необязательно
  size:
    min: 20                 # минимальная сторона территории, блоков
    max: 300                # максимальная сторона территории, блоков
  tag:
    min-length: 2
    max-length: 6
```

### Как заполнить каналы/роли
1. Создай в Discord 3-4 текстовых канала: например `#заявки-территорий`, `#список-общин`,
   `#лог-территорий`, `#территории` (последний — с самой панелью для игроков).
2. Включи Режим разработчика в Discord (Настройки → Расширенные), чтобы копировать ID по клику
   правой кнопкой.
3. Вставь ID каналов в `channels.review` / `channels.list` / `channels.log` / `channels.panel`.
4. Вставь ID ролей модераторов/админов в `admin-role-ids` (список, можно несколько через `-`).
5. Поставь `enabled: true`.
6. Перезапусти сервер (или `/sunshine reload`, если конфиг не требует пересоздания подключения к БД —
   при сомнении лучше просто перезапустить).

### Первый запуск
При первом старте с `territory.enabled: true` плагин сам создаст нужные таблицы в той же MySQL, где
уже лежат `player-db`/FlectonePulse — ничего вручную создавать не нужно.

## 4. Публикация панели для игроков

В канале, который указан в `territory.channels.panel`, выполни Discord-команду:

```
/setup-territory-panel
```

(нужны права Manage Server). Появится сообщение с кнопками:
* **📋 Подать заявку** — создать общину.
* **🏠 Моя община** — если есть община: владельцу — полная панель управления (добавить/исключить/
  передать/расширить/закрыть вход/удалить), обычному участнику — просмотр + «Покинуть общину».
* **🔍 Найти общину** — поиск по нику игрока, доступно всем.
* **🛠 Админ-панель** — видна и работает только ролям из `admin-role-ids`.

---

## 5. Опционально: BlueMap (территории на карте)

1. Поставь официальный плагин BlueMap в `plugins/` (обычный релизный jar, ничего не менять).
2. Больше ничего не требуется — SunShine сам обнаружит BlueMap при старте (проверяет один раз при
   запуске, если BlueMap поставили ПОСЛЕ старта SunShine — нужен рестарт сервера) и начнёт рисовать
   территории плоскими цветными полигонами на карте, с подписью владельца.
3. Если BlueMap не установлен — всё остальное (заявки, панель, TerritoryTitles) работает как обычно,
   просто без отрисовки на карте.

---

## 6. Опционально: тег общины в игровом чате

Discord-ник у привязанных игроков SunShine обновляет сам (формат `ТЕГ | ник`). Чтобы тег общины
показывался и в игровом чате/таблисте (это форматирует FlectonePulse, не SunShine), нужно:

1. Поставить PlaceholderAPI, если ещё не стоит.
2. В конфиге FlectonePulse (формат чата/таблиста) добавить один из плейсхолдеров SunShine:
   * `%sunshine_territory_prefix%` — сразу с разделителем, например `"ASL | "` (пусто, если игрок не
     в общине) — обычно его и нужно вставлять прямо перед ником.
   * `%sunshine_territory_tag%` — голый тег без разделителя, если нужно кастомное оформление.
   * `%sunshine_territory_name%` — полное название общины.
3. Пример: было `<player_name>`, стало `%sunshine_territory_prefix%<player_name>`.

Без этого шага теги всё равно видны в Discord-нике и на панели/в списке общин — просто не в самом
игровом чате.

---

## 7. Быстрая проверка, что всё работает

1. Зайди в игру, `/link` → привяжи Discord.
2. В канале с панелью нажми «📋 Подать заявку», заполни форму (название, тег, координаты двух углов,
   описание, «Да»).
3. Заявка должна появиться в `channels.review` с кнопками Одобрить/Отклонить.
4. Нажми «Одобрить» (от роли из `admin-role-ids`) — должно: создаться общиной в БД, появиться запись
   в `channels.list`, а в игре при входе на участок — показаться тайтл с названием общины.
5. Попробуй в игре сломать блок на территории другого игрока (если у общины включено `lock`/владелец
   закрыл вход) — должно быть заблокировано.
